GameplayCoreRoblox · Luau

Tags & Stats for Roblox gameplay

One small package that holds the state (tags) and the numbers (stats) of every character, so your stun, block, potion and weapon modules never fight each other.

Quick startAPI reference 
local entity = Core.Attach(character, { stats = { Speed = 16 } })

entity.Tags:Add("State.Stunned.Hard", "StunHandler", 2)   -- stunned for 2s
entity.Stats:AddModifier("Speed", { type = "Mult", value = 0.5, source = "Slow", duration = 3 })

print(entity.Tags:Has("State.Stunned"))   -- true
print(entity.Stats:Get("Speed"))          -- 8

Why GameplayCore?

Without a shared system, modules overwrite each other: a potion sets WalkSpeed = 20 and silently cancels the stun that set it to 0. GameplayCore lets each module declare what it does, and computes the correct result.

WithoutWith GameplayCore
isStunned = true everywhereA tag State.Stunned
WalkSpeed = WalkSpeed * 1.2A modifier on the Speed stat
Remember to restore valuesAutomatic expiry, or RemoveBySource
Modules overwrite each otherEffects stack and unstack cleanly

Core concepts

Entity

Someone with tags and stats: a player, an NPC, a boss. One per character.

Tag

A temporary label of what the entity is right now: State.Stunned. Present or absent.

Stat

A computed number: Speed, Damage. A base plus modifiers.

Source

Who applied a tag or modifier ("Potion", a tool). Used to remove things cleanly.

Dots build a hierarchy: holding State.Stunned.Hard also counts as holding State.Stunned and State.

Quick start

-- Core.Attach(owner, config)
--   owner  : usually the character Model (entity is cleaned up when it is destroyed)
--   config : { stats = {...}, strictStats = bool }  (both optional)
-- Returns the entity (.Tags and .Stats). Returns the existing one if already attached.
local entity = Core.Attach(character, {
	stats = { Speed = 16, Damage = 10 },   -- a number is a shortcut for { base = n }
})

entity.Tags:Add("State.Stunned.Hard", "StunHandler", 2)
print(entity.Tags:Has("State.Stunned"))    -- true, then false after 2s

entity.Stats:AddModifier("Speed", { type = "Flat", value = 4, source = "Boots" })
print(entity.Stats:Get("Speed"))           -- 20

entity.Stats:RemoveBySource("Boots")
print(entity.Stats:Get("Speed"))           -- 16

local same = Core.Get(character)           -- from any other script (nil if missing)

Tags

Declare your tags recommended

Strict mode turns typos like "State.Stuned" into clear errors.

Core.Tags.Define({
	State = {
		Stunned = { "Soft", "Hard" },   -- State.Stunned.Soft / .Hard
		Blocking = true,                -- State.Blocking
		Invulnerable = true,
	},
	Damage = { Fire = true },
})
Core.Tags.SetStrict(true)               -- unknown tags now throw

Names: letters, digits, _ and . only. Max 24 levels.

Add a tag

entity.Tags:Add(
	"State.Stunned.Hard",  -- tag      : required
	"StunHandler",         -- source   : who applies it (default "Default")
	2                      -- duration : seconds before auto-removal (nil = permanent)
)
-- Adding the same (tag, source) again refreshes it and keeps the LONGEST duration.
-- Another source can hold the same tag: it stays until ALL sources removed it.

Check tags

tags:Has("State.Stunned")          -- true if it OR a child is present (hierarchical)
tags:HasExact("State.Stunned")     -- true only if this exact tag was added
tags:HasAny({ "A", "B" })          -- at least one
tags:HasAll({ "A", "B" })          -- all of them
tags:Matches("State.*")            -- at least one STRICT descendant of State

-- Satisfies: one table for a whole condition (all fields optional, wildcards allowed)
tags:Satisfies({
	all  = { "State.Armed" },                       -- every one present
	any  = { "State.Idle", "State.Running" },       -- at least one present
	none = { "State.Stunned", "State.Silenced" },   -- none present
})

Multiple sources

tags:Add("State.Stunned.Hard", "BossSlam")
tags:Add("State.Stunned.Hard", "TrapSpikes")
tags:Remove("State.Stunned.Hard", "BossSlam")
print(tags:Has("State.Stunned.Hard"))   -- true, the trap still holds it
tags:Remove("State.Stunned.Hard", "TrapSpikes")
print(tags:Has("State.Stunned.Hard"))   -- false

Stats

How the final value is computed

value = (base + sum(Flat)) × (1 + sum(Increase)) × product(Mult)
Override active → it replaces the result, then clamp(min, max) and rounding
TypeMeaningvalueBase 16 →
FlatAdds a number420
IncreaseAdds a percentage (they add up together)0.25 = +25%20
MultMultiplies (they multiply together)1.2 = ×1.219.2
OverrideForces the final value00
-- (16 + 4) × (1 + 0.25 + 0.25) × 1.2 = 36
stats:AddModifier("Speed", { type = "Flat",     value = 4,    source = "Boots" })
stats:AddModifier("Speed", { type = "Increase", value = 0.25, source = "Potion" })
stats:AddModifier("Speed", { type = "Increase", value = 0.25, source = "Aura" })
stats:AddModifier("Speed", { type = "Mult",     value = 1.2,  source = "Buff" })

Define stats

Core.Attach(character, {
	stats = {
		Speed = 16,                                  -- shortcut for { base = 16 }
		Crit  = { base = 0.1, min = 0, max = 0.75 }, -- never below 0 or above 0.75
		Level = { base = 1.4, rounding = "floor" },  -- "floor" | "ceil" | "round"
	},
	strictStats = true,  -- unknown stat = error (default false: auto-created with base 0)
})
entity.Stats:Define("Armor", 5)   -- Define creates a stat later (or redefines an existing one)

Derived stats (formula)

entity.Stats:Define("Vitality", 10)
entity.Stats:Define("MaxHealth", {
	-- formula: a recipe the module runs for you. get(name) reads another stat.
	formula = function(get)
		return 100 + get("Vitality") * 10
	end,
})
print(entity.Stats:Get("MaxHealth"))     -- 200
entity.Stats:SetBase("Vitality", 20)
print(entity.Stats:Get("MaxHealth"))     -- 300, updated by itself

Dependencies are detected automatically. Modifiers apply on top of the formula result. A stat with a formula has no manual base (SetBase errors), and circular formulas throw.

Manage modifiers

modifier:Remove()            -- true if it was still active
modifier:SetValue(0.8)       -- change value, the stat recomputes
modifier:SetDuration(5)      -- remaining time = 5s (nil = permanent)
modifier:GetTimeLeft()       -- seconds left, nil if permanent
modifier:IsActive()

stats:RemoveBySource("IronSword")            -- on every stat, returns the count
stats:RemoveBySource("IronSword", "Speed")   -- only on Speed
stats:HasSource("IronSword")                 -- boolean
stats:Breakdown("Speed")   -- Base, Flat, Increase, Mult, Override, Value, Modifiers[] (great for tooltips)

Conditional modifiers

The feature that links everything. A modifier with a condition (same format as Satisfies) is active only while tags match, and the stat recomputes by itself when tags change.

-- Written ONCE when the entity is created
entity.Stats:AddModifier("Speed", {
	type = "Override", value = 0, priority = 100, source = "StunRule",
	condition = { all = { "State.Stunned" } },
})
entity.Stats:AddModifier("Speed", {
	type = "Mult", value = 0.6, source = "BlockRule",   -- -40% while blocking
	condition = { all = { "State.Blocking" } },
})

-- Your StunHandler now needs a single line:
entity.Tags:Add("State.Stunned.Hard", "StunHandler", 2)
Speed drops to 0 for 2 seconds, then comes back. The StunHandler knows nothing about speed, and speed knows nothing about the StunHandler. Core.Attach links tags and stats automatically.

Reacting to changes

-- Stat: callback(new, old) is called immediately with (value, value), then on every change
local conn = entity.Stats:Observe("Speed", function(new, old)
	humanoid.WalkSpeed = new
end)
entity.Stats.Changed:Connect(function(statName, new, old) end)   -- all stats

-- Tag: callback(present) is called immediately, then whenever it appears/disappears
entity.Tags:Observe("State.Stunned", function(present) end)
entity.Tags.TagAdded:Connect(function(tag) end)
entity.Tags.TagRemoved:Connect(function(tag) end)
entity.Tags:WaitFor("State.Grounded", 3)   -- yields; true if it appeared, false on timeout
Stat events are batched and deferred: ten modifiers in one frame fire one event with the final value, and no event if the net change is zero. Get() is always immediate. Use stats:Flush() to fire pending events now.

Using it with your modules

StunHandler

local function stun(targetModel, duration)
	local entity = Core.Get(targetModel)
	if not entity or entity.Tags:Has("State.Invulnerable") then return end
	entity.Tags:Add("State.Stunned.Hard", "StunHandler", duration)
end

CastHitbox

hitbox.OnHit:Connect(function(victimModel)
	local victim, attacker = Core.Get(victimModel), Core.Get(attackerModel)
	if not victim or not attacker or victim.Tags:Has("State.Invulnerable") then return end
	local damage = attacker.Stats:Get("Damage")
	if victim.Tags:Has("State.Blocking") then damage *= 0.3 end
	victimHumanoid:TakeDamage(damage)
end)

Humanoid & equipment

entity.Stats:Observe("Speed",     function(v) humanoid.WalkSpeed = v end)
entity.Stats:Observe("MaxHealth", function(v) humanoid.MaxHealth = v end)

stats:AddModifier("Damage", { type = "Flat", value = 15, source = tool })   -- equip
stats:RemoveBySource(tool)                                                  -- unequip: all gone

ProfileStore

Save base values, not computed values or temporary modifiers.

for name, base in profile.Data.Stats do entity.Stats:SetBase(name, base) end   -- on load
profile.Data.Stats.Vitality = entity.Stats:GetBase("Vitality")                   -- on save

Replication

You pick the transport (RemoteEvent, Blink, ByteNet…). The package gives you Serialize() and ApplySnapshot(). The server is the authority; clients only receive results, never modifiers.

-- SERVER
local function replicate(player, entity)
	local scheduled = false
	local function send()
		if scheduled then return end
		scheduled = true
		task.defer(function()   -- one send per frame
			scheduled = false
			remote:FireClient(player, entity.Tags:Serialize(), entity.Stats:Serialize())
		end)
	end
	entity.Tags.Changed:Connect(send)
	entity.Stats.Changed:Connect(send)
	send()
end

-- CLIENT
remote.OnClientEvent:Connect(function(tags, stats)
	entity.Tags:ApplySnapshot(tags)     -- diff: only real changes fire events
	entity.Stats:ApplySnapshot(stats)   -- server values become client bases
end)
